# From joining a new employee to daily attendance

This is how the process works **today**, step by step. It can change later based on feedback.

Product names are shown in **bold** so you can find the same screens in the website.

---

## Step 1 — Make the joining checklist (**Onboarding Templates**)

Before a new person joins, HR prepares a **joining checklist** for that job in **Onboarding Templates**.

Example: submit ID proof, fill bank details, collect laptop.

Until the checklist is published, it is only a plan — no real employee has started yet.

---

## Step 2 — Start joining for one employee (**Employee Onboarding**)

When a real person joins, HR opens **Employee Onboarding**, picks that person, and starts joining using the published checklist.

Then:

- **HR** can see progress and mark items done in **Employee Onboarding**  
- **The employee** can see pending items in **My Workspace**  

---

## Step 3 — Finish the joining items (**Employee Onboarding** / **My Workspace**)

Each checklist item is completed one by one.

Today, **HR** mostly marks items done in **Employee Onboarding**. The employee can see the list in **My Workspace**, but may complete some items themselves later (for example upload a file).

When everything is done, joining is closed.

---

## Step 4 — Make the work plan live (**Work Schedule**)

HR prepares who should work on which days in **Work Schedule**, then publishes it (makes it live).

If it is still a draft, attendance cannot start.

---

## Step 5 — Daily attendance (**My Workspace** / **Attendance**)

After **Work Schedule** is live:

- **The employee** marks in and out from **My Workspace**  
- **HR** reviews records in **Attendance**  

---

## Full flow (simple)

**Onboarding Templates → Employee Onboarding → finish tasks → Work Schedule (publish) → My Workspace check-in → Attendance review**
