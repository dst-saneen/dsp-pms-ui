# 16 — Operations (admin)

**Why this exists:** Platform operators watch email delivery and file storage. **Day-to-day company users do not need this.**

**Who:** Owner / platform-capable admin.

---

## Pages

Open these from the **Operations** and **Administration & Security** sidebar groups (pasting the nested URLs can 404 in local Turbopack):

| Menu | What it is for |
|------|----------------|
| Delivery Queue | Outbound mail jobs |
| Dead Letters | Permanently failed sends |
| File Operations | Storage / scan health |
| Document Retention | How long files are kept |

Also: Suppressions, Recipient Exceptions, HR → Recruitment → Delivery.

When delivery is not configured, the Delivery Queue is empty by design. Pages should still open. Do not treat an empty queue as a failed company setup.
