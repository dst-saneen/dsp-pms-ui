# 99 — Field glossary

Short meanings for options that confuse first-time users. Chapter numbers point to the full screen.

| Term | Meaning | See |
|------|---------|-----|
| Active | Record can be used in new work. Off = hidden/retired, not usually deleted. | 02 |
| Branch | Office / location. Owns departments. Timezone lives here. | 01, 02 |
| Business Calendar | Office open/closed and holidays. Not leave. | 05 |
| Check in / Check out | Attendance punch. Needs published roster + working day. | 09 |
| Clean (file) | Virus scan passed. Only Clean should download. | 08 |
| Company | Legal entity under a Company Group. | 01, 02 |
| Company Group | The organization / tenant you registered. | 01 |
| Convert | Recruitment: accepted offer becomes an Employee. | 06 |
| Day preview | Working days + balance impact shown before submitting leave. | 10 |
| Default shift | Shift used when an employee has no personal shift. Needed for roster generate. | 02, 05 |
| Department | Team under a branch. | 01, 02 |
| Designation | Job title. Leave matrix row. Onboarding template hangs here. | 02, 07, 10 |
| Draft vs Publish | Draft = editing. Publish = live for calendar, roster, or onboarding template. | 05, 07 |
| Employee | HR person record. | 04 |
| Employee Type | Free text (Permanent, Contract). | 04 |
| Generate (roster / balances) | Creates rows from rules. Dry run first. | 05, 10 |
| Grace in / out | Minutes late/early before attendance exception. | 02 |
| HR Request | Letter/paperwork while still employed. | 12 |
| Leave matrix | Designation × leave type = **days per year** (current UI). | 10 |
| Linked employee | Ties a User login to an Employee. Required for My Workspace. | 03 |
| Night Shift | Shift crosses midnight (end time earlier than start). | 02 |
| Office Finance path | Setup (profile → parties → categories → accounts → periods) then Transactions → Reports → Dashboard. | 14 |
| Onboarding (employee) | Joining checklist. Not the company setup hub. | 07 |
| Onboarding involvement departments | Departments that get tasks for this job title. Department only, not a named person. | 02, 07 |
| Open my workspace | Finishes organization hub; goes to Dashboard. | 01 |
| Organization Owner | Role created at register. Full tenant admin. | 01, 03 |
| Parent Company | Optional holding/subsidiary link. First company usually has none. | 02 |
| Period closing | Freeze an attendance period. | 09 |
| Preflight | Check before convert / payroll run. Failures are blockers. | 06, 15 |
| Publish | Make a draft live. | 05, 07 |
| Reporting Manager | Employee who does the first leave (and some other) approvals. | 04, 10 |
| Role | Which menus. | 03 |
| Scope | Where the role applies (group / company / branch). | 03 |
| Separation | Exit process. | 12 |
| Shift | Clock pattern for a working day. | 02, 05 |
| SSO | Single Sign-On. Not enabled here. | 01 |
| Timezone | Branch field. Punch and calendar days. Example `Asia/Kolkata`. | 02 |
| User | Login account. | 03 |
| Work Schedule | Roster of who works which day/shift. | 05 |

Generated codes (`COM-`, `BR-`, `EMP-`, asset codes) are **shown**, not typed.
