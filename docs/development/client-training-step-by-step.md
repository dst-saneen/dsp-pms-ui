# Staff Training Guide — Group ERP (Live)

**Live URL:** https://pms.datascapetek.com  
**Use this on Zoom / phone with client staff.** One section at a time. Pause and ask them to click with you.

---

## Before you start the call

| Check | Why |
|-------|-----|
| Site opens | https://pms.datascapetek.com |
| You have an Owner / Admin login | To demo setup |
| Email works for OTP / invites | Registration & invitations |
| Company is selected in top bar after login | Menus need Company |

**Roles you will mention:**
- **Owner / Admin** — setup, users, full control  
- **HR** — hire, onboarding, leave, documents, payroll prep  
- **Manager** — approve leave / OT / timesheets / tasks  
- **Employee** — My Workspace only (own data)  
- **Finance** — transactions (maker ≠ approver)  
- **IT / Asset** — laptops, licences  

---

## Call opening (30 seconds)

Say:

> “This is your company ERP.  
> Flow is: create company → set up office → hire people → onboard → daily work → assets/projects → finance → payroll.  
> Each person sees only what their role allows.  
> Always select **Company** in the top bar after login.”

---

## Session 1 — First-time setup (Owner)

### 1A. Create organization (open registration is ON)

1. Open https://pms.datascapetek.com/login  
2. Click **Create an organization**  
3. Enter organization name, owner name, email, strong password (password ≠ email)  
4. Verify OTP from email  
5. Complete onboarding wizard (first company, branch, department)  

**Teach:** “This creates your company group and first owner login.”

### 1B. Login every day

1. Login with username or email + password  
2. Top bar → select **Company**  
3. Select **Branch** if needed  

**Teach:** “If screens look empty, Company is not selected.”

### 1C. Office structure

**Menu:** Administration  

1. Companies  
2. Branches  
3. Departments  
4. Designations  
5. Shifts  

**Teach:** “Structure first. Then people.”

### 1D. Users & roles

**Menu:** Administration → Users  

1. Invite / create User  
2. Assign Role  
3. Link to Employee when they exist  

**Teach:**  
- **User** = login  
- **Employee** = person record  
- **Role** = which menus they see  

---

## Session 2 — Hire & onboard (HR + IT)

### 2A. Hire (Recruitment)

**Menu:** HR → Recruitment  

1. Openings → New → Publish  
2. Candidate applies (Careers / application)  
3. Interview → Offer → Accept  
4. Verify signed offer if asked  
5. **Convert** → Employee created  
6. Invitation email → employee sets password  

**Teach:** “New hires come from Recruitment → Convert. Prefer that over manual employee create.”

### 2B. Onboarding checklist

**Menu:** HR → Onboarding Templates / Employee Onboarding  

1. Create & publish Template (HR tasks, IT tasks, etc.)  
2. Start onboarding for the new employee  
3. Assign department work (IT gets laptop task)  
4. Complete checklist tasks  
5. Fulfil asset task if any  
6. Complete Onboarding → status **Active**  

**Teach:** “Template = plan. Employee Onboarding = real checklist.”

### 2C. Documents

**Menu:** HR → Employee Documents  

1. Categories / Types (setup once)  
2. Upload document  
3. Wait until Clean  
4. Verify or Reject  

**Teach:** “Upload → Clean → Verify.”

---

## Session 3 — Daily work (Employee + Manager + HR)

### 3A. Employee — My Workspace

**Menu:** My Workspace  

Show:
1. Attendance check-in / check-out  
2. Leave apply  
3. Own documents / assets  
4. Notifications (click title to open)  
5. Own payslips (after payroll)  

**Teach:** “My Workspace = only my data.”

### 3B. Leave / OT / Comp-off

1. Employee applies Leave (or OT)  
2. Manager approves  
3. HR may do final approve if configured  

**Teach:** “Request → Approve. Calendar/holidays control working days.”

### 3C. Attendance & calendar

**Menu:** HR → Attendance / Leave / Holidays / Business Calendar  

**Teach:** “HR sets calendar and policies. Employees follow them.”

---

## Session 4 — Assets (IT)

**Menu:** Asset Management  

1. Categories / Types (once)  
2. Create asset in inventory  
3. Assign to employee  
4. Employee acknowledges if asked  
5. Return / Transfer when needed  
6. Licences: do not exceed seats  

**Teach:** “One laptop = one active holder. Licence seats have a limit.”

---

## Session 5 — Projects (PM + team)

**Menu:** Projects  

1. Create Internal project → stages → team  
2. Create task → assign employee  
3. Activate project  
4. Employee starts → submits for review  
5. Manager returns or completes  
6. Timesheet → submit → manager approve  
7. Complete / archive project later  

**Teach:** “Project → Task → Timesheet. Manager approves hours.”

---

## Session 6 — Finance (Maker + Approver)

**Menu:** Office Finance  

1. Setup: profile, parties, categories, accounts, **open period**  
2. Transactions → Draft Income / Expense / Transfer  
3. Submit  
4. **Different user** Approves  
5. Reports / reverse if allowed  

**Rules to say every time:**
- Maker and Approver must be **different people**  
- Period must be **Open**  
- Locked period blocks new posts  

---

## Session 7 — Payroll (HR + Approver + Employee)

**Menu:** HR → Payroll  

1. Salary components (Basic, HRA, deductions…)  
2. Employee salary revisions  
3. Attendance period ready for payroll  
4. Create run for the month  
5. Calculate  
6. **Other user** Approves  
7. Mark Paid  
8. Employee → My Workspace → Payslip download  

**Rules:**
- Maker ≠ Approver  
- Same month cannot run twice as a duplicate paid run  
- Employee sees only own payslip

## Troubleshooting (say these if stuck)

| Problem | What to check |
|---------|----------------|
| Menu missing | Wrong role / permissions |
| Page empty / “select company” | Top-bar Company not selected |
| “Not enabled for this company” | Feature allowlist — tell your tech team |
| Cannot approve own Finance/Payroll | Correct — need second user |
| Create organization missing | Self-registration flag off on server |
| No OTP email | Check spam; ask tech (email enabled) |
| Payslip missing | Payroll must be Mark Paid first |

---

## Three rules to repeat often

1. Select **Company** after login  
2. **Maker ≠ Approver** for Finance and Payroll  
3. Employees use **My Workspace** for own data only
